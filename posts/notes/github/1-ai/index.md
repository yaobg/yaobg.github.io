## [AutoGPT](https://github.com/Significant-Gravitas/AutoGPT)

AutoGPT 是一个 开源的自动化 AI 代理（AI Agent），它可以自主执行任务，而无需人类的持续输入。它使用 GPT-4 或 GPT-3.5 作为核心模型，并结合
记忆、互联网搜索、文件处理、代码执行等工具，实现完全自动化的操作。

🌟 AutoGPT 的主要特点:

- 自主性：可以自主计划和执行任务，而不是简单地回答问题。
- 互联网访问：可以搜索和获取最新信息（例如市场分析、趋势报告）。
- 代码执行：可以运行 Python 代码，执行自动化任务。
- 文件管理：能创建、修改和存储文件。
- 长期记忆：能够记住以前的任务，并在后续任务中利用这些信息。
- 插件支持：支持与第三方 API（如 Twitter、Slack、邮件等）进行交互。

## [Gradio](https://www.gradio.app/)

![gradio.png](images/gradio.png)
Gradio 是一个 Python 库，用于 快速创建交互式 Web 应用，特别适用于 机器学习模型、深度学习 和 数据可视化。它可以让你用几行代码就能搭建一个
可视化界面（GUI），并且可以通过 Web 访问，无需复杂的前端开发。

💡 Gradio 的核心特点:

- 简单易用：几行代码就能创建一个 Web 界面，无需 HTML/CSS/JS 知识。
- 支持本地 & 在线分享：可以本地运行，也能自动生成一个 临时公网链接，方便分享。
- 适用于 AI/ML 模型：特别适合用于 机器学习、深度学习、NLP 任务 等，方便用户测试模型。
- 多种输入 & 输出组件：支持文本、图片、音频、视频、绘图等交互方式。
- 可与 Hugging Face 结合：可以直接部署到 Hugging Face Spaces。
